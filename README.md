# Halloween — Ночная ночь с тыквами

Играйте в одиночку, соревнуйтесь с ботом или зовите друга за одну клавиатуру. Собирайте светящиеся тыквы, уворачивайтесь от призраков и пройдите 15 уровней ночного леса.

## Запуск

Нужен Python 3.9 или новее. Откройте папку проекта в терминале VS Code и выполните:

```bash
python -m venv .venv
```

Активируйте окружение:

```bash
# macOS
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\Activate.ps1
```

Установите Pygame и запустите игру:

```bash
python -m pip install -r requirements.txt
python main.py
```

## Управление

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Движение | W, A, S, D | Стрелки (в режиме «С другом») |
| Выбор режима в меню | ← → или 1 / 2 / 3 | |
| Начать / дальше | Enter | Enter |
| Пауза / продолжить | P | P |
| Новый раунд | R | R |
| В меню | Esc | Esc |
| Выход из меню | Esc | Esc |

Собирайте тыквы, пока не появится переход на следующий уровень. Призрак отнимает жизнь, но после столкновения игрок ненадолго защищён. Раунд ограничен 90 секундами на уровень; каждый следующий уровень добавляет призраков и усложняет поляну.
